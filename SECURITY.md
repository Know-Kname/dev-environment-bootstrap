# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do NOT** open a public issue
2. Email: knowledgeknight99@protonmail.com
3. Include a description and steps to reproduce
4. Allow 48 hours for initial response

## Scope

This repository contains setup scripts that install software and configure credentials. Security concerns include:
- Hardcoded secrets or API keys
- Unsafe PowerShell execution policies
- Insecure download sources
- Credential storage vulnerabilities
